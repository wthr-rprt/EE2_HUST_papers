# Set Theory

This is an English translation of the original Vietnamese note. The Vietnamese note remains unchanged in the vault.

## 1. Sets

A set contains elements and subsets. If two sets are subsets of each other, then they are equal.

Sets can be represented by:

- listing elements,
- describing a rule,
- using a diagram.

## 2. Set operations

Set operations are similar to logical operations and digital logic.

- Intersection: $\cap$, analogous to AND
- Union: $\cup$, analogous to OR
- Difference: $\setminus$, analogous to AND NOT
- Symmetric difference: $\Delta$, analogous to XOR
- Cartesian product: $\times$, analogous to combinations

The Cartesian product is important in later chapters when we refer to powers such as $\mathbb{R}^2$ or $\mathbb{R}^3$.

For example:

- $\mathbb{R}^2 = \{(x,y) \mid x,y \in \mathbb{R}\}$
- $\mathbb{R}^3 = \{(x,y,z) \mid x,y,z \in \mathbb{R}\}$

This can be visualized as the plane or 3D space, though the analogy is only heuristic.

## 3. Properties of set operations

- Commutativity: valid for $\cup$, $\cap$, and $\Delta$
- Associativity: valid for repeated $\cup$, $\cap$, and $\Delta$
- Distributivity: valid for $\cup$ and $\cap$
- Difference properties
- De Morgan’s laws

### Cardinality and infinite sets

The size of a set is called its cardinality. Sets can be finite, countably infinite, or uncountably infinite.

- Finite sets have a finite number of elements.
- Countably infinite sets can be put into one-to-one correspondence with $\mathbb{N}$.
- Uncountably infinite sets cannot be enumerated by natural numbers.

This is a key concept in analysis and linear algebra.
