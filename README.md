# EE2_HUST_papers

This repository is a public **Obsidian vault** for organizing papers and notes related to the Automation Engineering at HUST. It is shared for public viewing and learning. The vault is a work in progress, and constructive criticism, corrections, and suggestions are very welcome. Some of the LaTeX may not work outside Obsidian, English version of the repo **IS NOT** the intended way to use this repo and may have plenty of errors, use at your own risk.

## Open the vault in Obsidian

1. Install [Obsidian](https://obsidian.md/) if you have not already.
2. Clone or download this repository to your computer. With Git installed, you can clone it from a terminal:

   ```bash
   git clone https://github.com/wthr-rprt/EE2_HUST_papers.git
   ```

   Alternatively, use GitHub's **Code → Download ZIP** option and extract the archive.
3. In Obsidian, choose **Open folder as vault** (or **Open folder**) and select the `EE2_HUST_papers` folder you cloned or extracted.
4. If Obsidian asks whether to trust the vault's authors, review the vault contents and choose the option that suits you. You can browse the notes without enabling community plugins.

## Keep the vault in sync with Obsidian Git

The [Obsidian Git](https://github.com/Vinzent03/obsidian-git) community plugin can help you pull updates and save your changes to GitHub from inside Obsidian.

1. Make sure [Git](https://git-scm.com/downloads) is installed. If you have not cloned the vault yet, clone it as described above; the plugin works with the local Git repository.
2. In Obsidian, open **Settings → Community plugins**, turn off Restricted mode if needed, then select **Browse** and search for **Obsidian Git**. Install and enable it.
3. If you plan to push changes, configure GitHub authentication for Git on your computer. The plugin uses Git, so make sure the repository's remote and your credentials are set up. You need write access to this repository to push directly; otherwise, create your own fork and work from that.
4. Before editing, use the plugin command **Pull** (or its equivalent in the command palette) to get the latest changes.
5. Edit or add Markdown notes in the vault. When ready, use **Create backup** / **Commit-and-sync** from the command palette to commit and push your work. Review the changes and commit message before syncing.
6. If you work on more than one device, pull before editing and commit/push after editing to reduce conflicts. Resolve any Git conflicts before continuing.

Plugin command names and settings can vary by version. For more detail, see the [Obsidian Git documentation](https://github.com/Vinzent03/obsidian-git).
